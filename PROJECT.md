# Project: TrustTrace-AI

## 1. Goal
Build an autonomous, self-auditing credit underwriting engine (Hackathon Track 3: Reasoning Architecture). The system bridges quantitative ML (XGBoost) with qualitative LLM reasoning to detect algorithmic bias, ground reasoning in SHAP values, and execute state rollbacks for EU AI Act compliance.

## 2. Scope & Non-Goals
- **In Scope:** A Planner-Executor-Evaluator agentic loop (LangGraph). Generating and testing adversarial edge cases (Bias Flip, SHAP Contradictions, High-Risk Rollbacks). Auditing via Zetaris SQL and memory retrieval via Meterless H-MEM. A Streamlit UI showing the live reasoning DAG and rollback events.
- **Non-Goals:** Production-level banking security, real-time core banking API integrations, or training a custom LLM from scratch.

## 3. Tech Stack
- **Language/IDE:** Python 3, VS Code (using `opencode` assistant).
- **Agent Framework:** LangGraph (State Machine), Pydantic (Structured Outputs).
- **ML:** XGBoost, SHAP (trained on UCI German Credit Dataset).
- **Data/Audit (Required):** Zetaris (REST API for SQL audit logging).
- **Memory/Power (Required):** Meterless Nightshift (H-MEM for past verdicts, NVIDIA Nemotron via Nightshift for LLM inference).
- **UI:** Streamlit.

## 4. Constraints
- **Data:** Must use `german_credit.csv` as the baseline.
- **Security:** Never hardcode API keys. Use `.env` for Zetaris and Nightshift credentials.
- **Guardrails:** The Evaluator must use *deterministic rules* (Python) to check SHAP values against LLM text, not just another LLM call.
- **Sponsor Rule:** Nightshift must be the primary AI provider (do not call NVIDIA APIs directly).
